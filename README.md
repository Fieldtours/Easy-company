# Easy Company Field Guides

Free battlefield guides that follow Easy Company, 506th Parachute Infantry, 101st Airborne Division, from the night drop into Normandy to the end of the war in the Alps.

Part of the **Fieldtours** collection.

## What's in here

| File or folder | What it is |
| --- | --- |
| `index.html` | Start page: welcome screen, choose a campaign, PDF downloads |
| `normandy.html` | Normandy guide (6 June – 12 July 1944) |
| `holland-bastogne.html` | Holland & Bastogne guide (Sep 1944 – Feb 1945) |
| `germany-austria.html` | Germany & Austria guide (April – November 1945) |
| `audio/` | The spoken stories for each stop |
| `maps/` | Map pictures used inside the guides |
| `weapons/` | Drawings from the original 1940s US Army manuals |
| `pdf/` | Printable guides, and `pdf/manuals/` with the original manual pages |
| `fonts/`, icons, `welcome*.jpg` | Lettering, app icons and the welcome artwork |
| `sw.js`, `site.webmanifest`, `_headers` | Lets the site install like an app and work offline |

## Publishing

The whole folder is the website. It is published on Netlify exactly as it is: no build step.
